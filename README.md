# 厉志鹏 — 简历介绍

基于 React + Tailwind CSS 构建的个人简历展示页面，单文件部署，开箱即用。

## 技术栈

- React 19
- Tailwind CSS
- Vite (构建工具)

## 使用方式

直接用浏览器打开 `resume.html` 即可查看简历页面。

## 开发

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 构建
npm run build
```

## 部署

将 `resume.html` 上传至任意静态服务器即可，支持：

- GitHub Pages
- Vercel
- Netlify
- Nginx / Apache
